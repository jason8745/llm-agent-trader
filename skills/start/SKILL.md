# 開始使用 llm-agent-trader

依下列順序引導使用者。每一步完成後再進行下一步，並以正式書面中文說明；用語規範與 `trader` skill 相同。不得在使用者提出研究需求之前自行執行回測。

## 1. 確認工具可用

先告知使用者：第一次呼叫工具時，系統會下載回測引擎所需的套件（pandas、numpy、yfinance，約 50 MB），視網路狀況需要一至數分鐘，之後的呼叫只需數秒。

接著呼叫 `search_stock`，查詢「台積電」。

- 回傳含 `2330.TW` 的表格：工具運作正常，進行下一步。
- 工具不存在：請使用者在 Claude Code 輸入 `/mcp`，確認清單中有 `plugin:llm-agent-trader:trader` 且狀態為 connected。若沒有，請使用者依 README 的 Install 章節完成安裝，安裝後重新啟動 Claude Code 或執行 `/reload-plugins`。
- 回傳「trader 伺服器無法啟動」：將錯誤訊息原文告知使用者，並請使用者確認 `uv --version` 可以執行。

## 2. 說明工作資料夾

說明策略與回測紀錄都存放在目前的工作資料夾：

- 策略檔：`strategies/<名稱>.py`
- 回測紀錄：`.trader/runs.db`

建議每個研究主題使用一個資料夾。下次在同一個資料夾啟動 Claude Code，即可延續先前的研究。

## 3. 開啟檢視器

呼叫 `open_dashboard`，並將回傳的網址告知使用者。說明：

- 檢視器左側依股票分組，列出此資料夾的所有研究與每次迭代；中間以圖表為主（K 線與成交量、累積報酬率、回撤），上方標示本次假設與重點數字；右側為結論、兩段期間對照、發現與洞察與盤勢表現。
- 建議將檢視器放在 Claude Code 旁邊。新的回測完成後會在數秒內自動顯示，不需要重新整理。
- 檢視器隨 Claude Code 結束而停止。之後只要請 Claude 打開 dashboard，即可再次開啟。

## 4. 說明研究流程

以三至五句說明：

1. 使用者描述想研究的標的、期間與交易想法。
2. 第一次回測前，Claude 會逐題確認五項研究條件：標的、策略邏輯與初始參數、策略開發期間、策略執行期間、初始資金與費用。每題附有建議，回覆「yes」即可採用。
3. 策略開發期間用於設計與調整策略；策略執行期間模擬定稿後實際執行，以初始資金空手開始，不參與調整。兩段都與買進並持有基準比較，並列後可以看出策略是否過度擬合。
4. 檢視器顯示「⚑」時，代表策略開發期間的年化報酬率較策略執行期間高出逾 15 個百分點，可能過度擬合。
5. 定稿時，Claude 會在檢視器寫入結論：一句總結，加上數組「發現與洞察」，涵蓋過度擬合、與買進並持有基準比較、盤勢分段（上漲段、盤整段、下跌段）與統計可信度。

## 5. 提供範例並詢問研究主題

提供下列範例需求，並詢問使用者想研究的主題：

- 我想研究台積電的趨勢追蹤策略。請使用 2023-01-01 至 2025-12-31 的資料，設計一個均線類策略並回測，至少迭代兩次，最後告訴我結論。
- 請以 0050 測試 RSI 超賣進場、超買出場的策略，期間為 2020-01-01 至 2025-12-31，並與買進並持有基準比較。
- 請比較聯發科在 2022-01-01 至 2025-12-31 期間，均線交叉與布林通道兩種策略在策略執行期間的表現。

使用者提出需求後，依 `trader` skill 的研究流程進行。

## 已有研究紀錄時

若使用者表示要延續先前的研究，先呼叫 `list_runs` 列出既有回測，再呼叫 `open_dashboard`，並請使用者指定要延續的策略。
